\# Лабораторная работа №1. 



\## Задание



Написать программу на языке C++ для перемножения двух квадратных матриц.



\- \*\*Входные данные\*\*: файлы `A.txt` и `B.txt` со значениями исходных матриц.

\- \*\*Выходные данные\*\*: файл `C.txt` со значениями результирующей матрицы, время выполнения, объём задачи.

\- \*\*Верификация\*\*: обязательна автоматизированная проверка результатов с помощью сторонних библиотек (NumPy).



\## Реализация



Программа состоит из трёх частей:



1\. \*\*`gen.py`\*\* — генератор исходных матриц `A.txt` и `B.txt` заданного размера.

2\. \*\*`main.cpp`\*\* — основная программа: читает матрицы из файлов, перемножает их вложенными циклами, записывает результат в `C.txt`.

3\. \*\*`verify.py`\*\* — верификация результата с помощью NumPy: заново перемножает A и B и сравнивает с `C.txt`.



\### Алгоритм умножения



Используется классический тройной цикл без библиотек:



for (int i = 0; i < n; i++)

&#x20;   for (int j = 0; j < n; j++)

&#x20;       for (int k = 0; k < n; k++)

&#x20;           res\[i]\[j] += mat1\[i]\[k] \* mat2\[k]\[j];



Объём задачи: `2·n³` операций (n умножений и n сложений на каждый из n² элементов результата).

\- \*\*Компилятор\*\*: MSVC (Visual Studio 2022), Release x64

\- \*\*Размеры матриц\*\*: 200, 400, 800, 1000, 1200, 1600, 2000
